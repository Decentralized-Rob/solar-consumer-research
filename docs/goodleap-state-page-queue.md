# GoodLeap state page queue

Published at launch: Minnesota, Virginia.

Next evidence review: Maryland, Texas, Florida.

Secondary research queue: New Jersey, Missouri, Ohio, Michigan.

A state gets a dedicated GoodLeap page only when the primary record supports a useful homeowner-facing story. Until then, the GoodLeap tracker links to the existing SolarComplaint.com state hub. This prevents thin pages and keeps state resources centralized.
