# GoodLeap Hub Linking and Source Standard

## Purpose

Every GoodLeap FLAG state page must be integrated into SolarComplaint.com rather than operate as a parallel state directory. The GoodLeap page owns the GoodLeap-specific state record. The main SolarComplaint state page owns broader state consumer infrastructure.

## Required internal links on each FLAG state page

1. Link near the top to `/states/{state-slug}` using descriptive state-specific anchor text such as `Texas solar consumer resources`.
2. Link to `/federal-resources` when federal consumer-finance or solar resources are relevant.
3. Link back to `/goodleap/states`.
4. Link to the most relevant GoodLeap issue path, case index, or research page where it materially helps the reader.
5. Add contextual links to existing SolarComplaint installer, case, enforcement, or guide pages when those pages directly overlap the state-specific record.

The corresponding main SolarComplaint state page should eventually link back to the GoodLeap FLAG page when the FLAG page is substantive and indexable.

## External-source hierarchy

Prefer sources in this order:

1. Official state or federal agency records: attorney general, financial regulator, licensing agency, public utility regulator, CFPB, FTC, DOJ, bankruptcy court or other government source.
2. Primary court documents and published opinions.
3. Statutes, regulations, administrative rules, official licensing/search tools and official complaint channels.
4. Company statements or filings, clearly identified as company sources.
5. Independent reporting where it adds facts or context unavailable in primary sources.
6. Complaint/review/community material only when clearly labeled and used for consumer-experience context, not as proof of a factual claim.

## Link-quality rules

- Do not target a numeric quota. Add a link because it helps verify a claim, lets a consumer take an official next step, or provides useful context.
- Prefer the closest primary source rather than a page that merely summarizes that source.
- Use descriptive, concise anchor text. Avoid generic `click here`, `website`, or repeated keyword-stuffed anchors.
- Do not stack many adjacent links without explanatory context.
- Important internal pages must be reachable through normal crawlable links.
- Do not create reciprocal links solely to manipulate rankings. Cross-link state and GoodLeap pages because the topics genuinely overlap.
- Do not use `nofollow` on trustworthy editorial citations merely because they are external. Use appropriate qualification for sponsored, user-generated, or untrusted links if those are ever introduced.
- Check external links before launch and during periodic content review. Replace dead links with official successor URLs or archived primary records where appropriate.

## State-page minimum source mix

A substantive FLAG state page should normally include, where they exist:

- the strongest GoodLeap-specific case/enforcement primary source;
- the state Attorney General consumer complaint channel;
- the relevant state licensing, financial-regulator, solar-retailer, or utility-regulator resource;
- at least one federal consumer-finance/solar resource when the issue involves lending, disclosures, credit, or federal law;
- direct court opinions/orders for any court holdings summarized on the page.

This is a quality floor, not a requirement to manufacture links where no relevant authority exists.

## Editorial separation

- A complaint allegation is not a court finding.
- An arbitration order is not a merits ruling on the underlying consumer claims.
- Broader state solar enforcement must not be presented as GoodLeap-specific unless GoodLeap is actually named.
- Statistics covering multiple defendants must not be attributed to GoodLeap alone unless the source isolates GoodLeap's share.

## SEO basis

The standard follows current Google and Bing guidance: use crawlable internal links, descriptive contextual anchor text, people-first content, trusted external citations, and quality over quantity. There is no fixed ideal number of links per page.
