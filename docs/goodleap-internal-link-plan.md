# GoodLeap internal link strategy

## Strong reciprocal links for launch
- `/research` -> `/goodleap` with plain-language anchor around GoodLeap solar financing research.
- `/states/minnesota` -> `/goodleap/states/minnesota`.
- `/states/virginia` -> `/goodleap/states/virginia`.
- `/states/maryland`, `/states/texas`, `/states/florida` -> `/goodleap` only where the surrounding copy identifies the specific public record under review.
- `/cases/titan-solar-power` -> `/goodleap` only in financing/installer-overlap context.

## Hub outbound links
The GoodLeap hub links to the state tracker, published state pages, current MN/VA state hubs, MD/TX/FL state hubs, Titan research, Research, Resources, Methodology, Corrections and free research assistance.

## Avoid
- Sitewide GoodLeap links with no topical context.
- Thin state pages created only for SEO.
- Treating a GoodLeap license as evidence of a dispute.
- Linking procedural rulings with anchor text implying liability or wrongdoing.
